
# Telegram APK Customizer Bot

هذا البوت مصمم لتخصيص ملفات APK ديناميكيًا وتوقيعها لكل مستخدم بشكل آلي ومنعزل، وهو مهيأ للعمل على منصة Render.

## المميزات

- **تخصيص ديناميكي:** يقوم بكتابة توكن المستخدم في `assets/token.txt` داخل الـ APK.
- **توقيع آلي:** يستخدم `apksigner` و `zipalign` لتوقيع التطبيق ليكون جاهزاً للتثبيت.
- **دعم التزامن العالي:** يستخدم أدلة مؤقتة فريدة لكل مستخدم لمنع تداخل البيانات.
- **تنظيف فوري:** يحذف جميع الملفات المؤقتة بعد إرسال الـ APK للمستخدم لضمان كفاءة مساحة التخزين.
- **جاهز للنشر:** يتضمن `Dockerfile` متكامل مع جميع التبعيات (Java, Android Build Tools).

## تعليمات النشر على Render

1.  **رفع الكود:** قم برفع هذا المجلد إلى مستودع GitHub الخاص بك.
2.  **إنشاء خدمة جديدة:** في لوحة تحكم Render، أنشئ "Web Service" جديدة واربطها بمستودعك.
3.  **إعدادات البيئة:**
    -   **Runtime:** اختر `Docker`.
    -   **Environment Variables:** أضف المتغير التالي:
        -   `TELEGRAM_BOT_TOKEN`: توكن بوت تيليجرام الخاص بك.
4.  **ملف APK الأساسي:** تأكد من وضع ملف الـ APK الذي تريد استخدامه كقالب في `data/apks/base.apk`.

## هيكل المشروع

-   `src/main.py`: الكود الأساسي للبوت ومنطق معالجة الـ APK.
-   `Dockerfile`: إعدادات البيئة وتثبيت Java وأدوات Android.
-   `data/apks/base.apk`: ملف الـ APK القالب (يجب استبداله بملفك الحقيقي).
-   `data/keystore/`: سيتم توليد ملف التوقيع هنا تلقائيًا أثناء بناء Docker.
-   `requirements.txt`: مكتبات Python المطلوبة.

## ملاحظات هامة

-   تم ضبط الـ Dockerfile لتوليد مفتاح توقيع (Keystore) تجريبي تلقائيًا. للاستخدام الاحترافي، يفضل استخدام مفتاح توقيع خاص بك وتمريره كسر (Secret).
-   يجب أن يحتوي ملف الـ APK الأساسي على مجلد `assets` ليتمكن البوت من إضافة ملف `token.txt` بداخله.
